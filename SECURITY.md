# Security Policy

## Supported versions

Sitemon has no tagged releases. Only the latest commit on `trunk` is supported, and fixes land there.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report privately through GitHub's private vulnerability reporting: open the
[Security tab](https://github.com/mralaminahamed/sitemon/security) and choose
**Report a vulnerability**.

Include the affected service (gateway, checker, scheduler, notifier, ai, cli, web or infra),
the commit you tested, steps to reproduce, and the impact you observed.

Follow-up happens on the private advisory thread.
